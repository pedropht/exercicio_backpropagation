# Atividade
O projeto é formado pela implementacao do algoritmo forward / back propagation utilizando apenas bibliotecas básicas de manipulação de arrays e operações matemáticas.
Foi utilizado o dataset iris.csv para implementar uma tarefa de **classificação** multiclasse.

Diretório: \implementacao\

# Complemento
Foi disponibilizada uma ferramenta codificada com agentes de IA para visualização do processo de treinamento passo-a-passo da rede.
